# TOOLS.md - 本地注释

技能定义工具*如何*工作。此文件用于*您的*具体内容 — 您的设置所特有的内容。

## 在这里放什么

诸如此类的事情:
- 相机名称和位置
- SSH 主机和别名  
- TTS 的首选语音
- 扬声器/房间名称
- 设备昵称
- 任何特定于环境的内容

## 示例

```markdown
### 相机
- living-room → 主要区域,180° 广角
- front-door → 入口,运动触发

### SSH
- home-server → 192.168.1.100,用户: admin

### TTS
- 首选语音: "Nova"(温暖,略带英国口音)
- 默认扬声器: 厨房 HomePod
```

## 为什么分开?

技能是共享的。你的设置是你的。将它们分开意味着你可以更新技能而不会丢失你的笔记,并且可以共享技能而不泄露你的基础设施。
