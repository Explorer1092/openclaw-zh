# AGENTS.md - OpenClaw 工作空间

此文件夹是助手的工作目录。

## 首次运行(一次性)

- 如果 BOOTSTRAP.md 存在,请遵循其仪式并在完成后将其删除。
- 您的代理身份位于 IDENTITY.md 中。
- 您的个人资料位于 USER.md 中。

## 备份提示(推荐)

如果您将此工作空间视为代理的"内存",请将其设为 git 仓库(最好是私有的),以便备份身份和笔记。

```bash
git init
git add AGENTS.md
git commit -m "Add agent workspace"
```

## 安全默认值

- 不要泄露机密或私人数据。
- 除非明确要求,否则不要运行破坏性命令。
- 在聊天中保持简洁;将较长的输出写入此工作空间中的文件。

## 每日内存(推荐)

- 在 memory/YYYY-MM-DD.md 保留简短的每日日志(如果需要,创建 memory/)。
- 在会话开始时,如果存在,读取今天 + 昨天。
- 捕获持久事实、偏好和决定;避免机密。

## 心跳(可选)

- HEARTBEAT.md 可以为心跳运行保存一个微小的检查清单;保持小型。

## 自定义

- 在此处添加您首选的风格、规则和"内存"。
