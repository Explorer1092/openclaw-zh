# TOOLS.md - 用户工具注释(可编辑)

此文件用于*您的*关于外部工具和约定的注释。
它不定义哪些工具存在;OpenClaw 在内部提供内置工具。

## 示例

### imsg
- 发送 iMessage/SMS: 描述谁/什么,发送前确认。
- 更喜欢短消息;避免发送机密。

### sag
- 文本转语音: 指定语音、目标扬声器/房间以及是否流式传输。

添加您希望助手了解的关于您的本地工具链的任何其他内容。
