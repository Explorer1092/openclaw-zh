感谢你帮助提升 OpenClaw 的安全性。这个威胁模型是一个活动文档，我们欢迎任何人的贡献——你不需要是安全专家。

## 贡献方式

### 添加威胁

发现了我们尚未涵盖的攻击向量或风险？在 [openclaw/trust](https://github.com/openclaw/trust/issues) 上提交 issue，用你自己的语言描述即可。你不需要了解任何框架或填写每个字段——只需描述场景。

**有帮助的信息（但非必需）：**

- 攻击场景及其可能被利用的方式
- OpenClaw 的哪些部分受影响（CLI、Gateway、Channel、ClawHub、MCP 服务器等）
- 你认为的严重程度（低/中/高/严重）
- 相关研究、CVE 或真实世界示例的链接

我们会在审查期间处理 ATLAS 映射、威胁 ID 和风险评估。如果你想包含这些细节，很好——但不是必需的。

> **这是用于添加到威胁模型的，而非报告已知的漏洞。** 如果你发现了可利用的漏洞，请参见我们的[信任页面](https://trust.openclaw.ai)获取负责任的披露说明。

### 建议缓解措施

有解决现有威胁的想法？提交一个引用该威胁的 issue 或 PR。有用的缓解措施是具体且可操作的——例如，"Gateway 层面每发件人每分钟 10 条消息的速率限制"比"实施速率限制"更好。

### 提出攻击链

攻击链展示多个威胁如何组合成一个现实的攻击场景。如果你看到危险的组合，描述步骤以及攻击者如何将它们链接在一起。关于攻击在实践中如何展开的简短叙述比正式模板更有价值。

### 修复或改进现有内容

拼写错误、澄清说明、过时信息、更好的示例——欢迎提交 PR，无需提 issue。

## 我们使用的内容

### MITRE ATLAS 框架

这个威胁模型基于 [MITRE ATLAS](https://atlas.mitre.org/)（AI 系统的对抗性威胁图谱），这是一个专为 AI/ML 威胁设计的框架，涵盖提示词注入、工具滥用和 Agent 利用等。你不需要了解 ATLAS 就能做出贡献——我们在审查期间将提交内容映射到框架。

### 威胁 ID

每个威胁获得一个类似 `T-EXEC-003` 的 ID。类别如下：

| 代码    | 类别                                   |
| ------- | -------------------------------------- |
| RECON   | 侦察——信息收集                         |
| ACCESS  | 初始访问——获得入口                     |
| EXEC    | 执行——运行恶意操作                     |
| PERSIST | 持久化——维持访问                       |
| EVADE   | 防御规避——避免检测                     |
| DISC    | 发现——了解环境                         |
| EXFIL   | 数据渗漏——窃取数据                     |
| IMPACT  | 影响——破坏或干扰                       |

ID 由维护者在审查期间分配。你不需要自己选择。

### 风险级别

| 级别         | 含义                                                              |
| ------------ | ----------------------------------------------------------------- |
| **严重**     | 完全系统入侵，或高可能性 + 严重影响                               |
| **高**       | 可能造成重大损害，或中等可能性 + 严重影响                         |
| **中**       | 中等风险，或低可能性 + 高影响                                     |
| **低**       | 不太可能且影响有限                                                |

如果你不确定风险级别，只需描述影响，我们会进行评估。

## 审查流程

1. **分类**——我们在 48 小时内审查新提交
2. **评估**——我们验证可行性，分配 ATLAS 映射和威胁 ID，验证风险级别
3. **文档**——我们确保所有内容格式正确且完整
4. **合并**——添加到威胁模型和可视化中
