# `openclaw dns`

广域发现(Tailscale + CoreDNS)的 DNS 助手。目前专注于 macOS + Homebrew CoreDNS。

相关:
- Gateway发现:[发现](/gateway/discovery)
- 广域发现配置:[配置](/gateway/configuration)

## 设置
