# `openclaw setup`

初始化 `~/.openclaw/openclaw.json` 和 Agent 工作区。

相关:

- 入门:[入门](/start/getting-started)
- CLI 入职:[入职向导 (CLI)](/start/wizard)

## 示例

```bash
openclaw setup
openclaw setup --workspace ~/.openclaw/workspace
```

通过设置运行向导:

```bash
openclaw setup --wizard
```
