# File Transfer Plugin

通过专用 Node 命令在已配对 Node 上获取、列举和写入文件。通过 node.invoke 上的 base64 绕过 bash 标准输出截断，支持最大 16 MB 的二进制文件。

## 分发

- 包名：`@openclaw/file-transfer`
- 安装方式：OpenClaw 内置
