# Qwen Plugin

为 OpenClaw 添加 Qwen、Qwen Cloud、Model Studio、DashScope 模型 Provider 支持。

## 分发

- 包名：`@openclaw/qwen-provider`
- 安装方式：内置于 OpenClaw

## 接口

providers: qwen, qwencloud, modelstudio, dashscope; contracts: mediaUnderstandingProviders, videoGenerationProviders
