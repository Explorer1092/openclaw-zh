# Plugin 清单

本页面从 `extensions/*/package.json`、`openclaw.plugin.json` 和根 npm Package `files` 排除项生成。使用以下命令重新生成：

```bash
pnpm plugins:inventory:gen
```

## 定义

- **核心 npm Package：** 内置于 `openclaw` npm Package 中，无需单独安装 Plugin 即可使用。
- **官方外部 Package：** OpenClaw 维护的 Plugin，从核心 npm Package 中省略，保存在此官方清单中，可通过 ClawHub 和/或 npm 按需安装。
- **仅源码检出：** 从已发布 npm 工件中省略的仓库本地 Plugin，不作为可安装 Package 宣传。

源码检出与 npm 安装不同：`pnpm install` 后，捆绑 Plugin 从 `extensions/<id>` 加载，因此本地编辑和 Package 本地工作区依赖项可用。

## 安装 Plugin

使用 **Distribution** 列决定是否需要安装。显示 `included in OpenClaw` 的 Plugin 已存在于核心 Package 中。官方外部 Package 需要一次安装，然后重启 Gateway。

例如，Discord 是官方外部 Package：

```bash
openclaw plugins install @openclaw/discord
openclaw gateway restart
openclaw plugins inspect discord --runtime --json
```

在发布切换期间，普通裸 Package 规格仍然从 npm 安装。当您需要明确的来源时，使用 `clawhub:@openclaw/discord` 或 `npm:@openclaw/discord`。安装后，按照 Plugin 的设置文档（例如 [Discord](/channels/discord)）添加凭证和 Channel 配置。有关更新、卸载和发布命令，请参见[管理 Plugin](/plugins/manage-plugins)。
